---
name: Wellness pattern language
description: Safety boundary for Future Me wellbeing comparisons and interpretation.
---

Future Me must not diagnose users or say that a recorded habit caused how someone feels. Show only logged data, keep missing values absent, and describe repeated overlaps as “Your logs show a pattern worth watching,” while stating that records cannot establish a cause.

**Why:** The user explicitly required that this feature never diagnose or claim a cause.

**How to apply:** When building or revising feelings and behavior comparisons, use descriptive nonclinical language, compare only matched logged dates, and show the sparse-data message when evidence is limited.
